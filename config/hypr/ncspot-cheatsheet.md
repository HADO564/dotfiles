# spotify-player Cheatsheet

---

## Playback
| Key | Action |
|---|---|
| `Space` | Play / Pause |
| `Enter` | Play selected item |
| `n` | Next track |
| `p` | Previous track |
| `+` / `-` | Volume up / down |
| `r` | Toggle repeat |
| `s` | Toggle shuffle |
| `Ctrl+s` | Save track to liked songs |
| `.` / `,` | Seek forward / backward |

## Navigation
| Key | Action |
|---|---|
| `j / k` | Move down / up |
| `g` | Go to top |
| `G` | Go to bottom |
| `Ctrl+d` | Page down |
| `Ctrl+u` | Page up |
| `Enter` | Open / select item |
| `Backspace` | Go back |
| `q` | Quit |

## Pages
| Key | Action |
|---|---|
| `1` | Playlists |
| `2` | New Releases |
| `3` | Liked Tracks |
| `4` | Recently Played |
| `5` | Top Tracks |
| `6` | Top Artists |
| `7` | Followed Artists |
| `8` | Saved Albums |
| `9` | Saved Podcasts |

## Search
| Key | Action |
|---|---|
| `/` | Open search |
| `Enter` | Submit search |
| `Esc` | Cancel |

## Queue & Library
| Key | Action |
|---|---|
| `a` | Add to queue |
| `d` | Remove from queue |
| `Ctrl+s` | Save / unsave item |

## Spotify Connect
| Key | Action |
|---|---|
| `D` | List & switch Spotify devices |

## Misc
| Key | Action |
|---|---|
| `?` | Show help |
| `C` | Show context (current album/playlist) |
| `l` | Show lyrics (synced) |
| `O` | Open in browser |

---

> Press `?` inside spotify-player for the full built-in help.
