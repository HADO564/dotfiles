# ⌨  Hyprland Keybindings

---

## 🚀  Applications

| Shortcut               | Action                          |
| ---------------------- | ------------------------------- |
| `Super + Q`            | Terminal (kitty)                |
| `Super + B`            | Browser (Zen)                   |
| `Super + C`            | Editor (VSCode)                 |
| `Super + E`            | File manager (Thunar)           |
| `Super + R`            | App launcher (rofi)             |
| `Alt + Space`          | App launcher (rofi)             |
| `Super + V`            | Clipboard history picker        |
| `Super + Shift + C`    | Color picker                    |
| `Super + W`            | Wallpaper picker (waypaper)     |
| `Super + F1`           | **This cheat sheet**            |

---

## 🪟  Window Management

| Shortcut                    | Action                          |
| --------------------------- | ------------------------------- |
| `Super + X`                 | Close focused window            |
| `Super + F`                 | Toggle float                    |
| `Super + P`                 | Toggle pseudotile (dwindle)     |
| `Super + J`                 | Toggle split direction          |
| `Super + M`                 | Show / restore minimized windows|
| `Super + ← ↑ ↓ →`          | Move focus                      |
| `Super + Alt + ← ↑ ↓ →`    | Resize active window            |
| `Super + drag (LMB)`        | Move floating window            |
| `Super + drag (RMB)`        | Resize floating window          |

### Title Bar Buttons

| Button         | Action                          |
| -------------- | ------------------------------- |
| 🟢 Green (left)  | Minimize to special workspace   |
| 🟡 Yellow (mid)  | Maximize                        |
| 🔴 Red (right)   | Close window                    |

---

## 🗂️  Workspaces

| Shortcut                   | Action                              |
| -------------------------- | ----------------------------------- |
| `Super + 1 – 0`            | Switch to workspace 1–10            |
| `Super + Shift + 1 – 0`    | Move window to workspace 1–10       |
| `Super + Scroll`           | Cycle through workspaces            |
| `Super + S`                | Toggle scratchpad                   |
| `Super + Shift + S`        | Move window to scratchpad           |

---

## 📸  Screenshots

| Shortcut           | Action                                      |
| ------------------ | ------------------------------------------- |
| `Print`              | Capture area → clipboard                    |
| `Shift + Print`      | Capture whole screen → clipboard            |
| `Super + Print`      | Capture area → save to ~/Pictures           |
| `Ctrl + Super + F`   | Capture whole screen → clipboard + save to ~/Pictures   |
| `Ctrl + Super + S`   | Capture area → clipboard + save to ~/Pictures           |

## 🔊  Media & Hardware Keys

| Key                  | Action                    |
| -------------------- | ------------------------- |
| `Volume Up / Down`   | ±5% volume                |
| `Mute`               | Toggle speaker mute       |
| `Mic Mute`           | Toggle microphone mute    |
| `Brightness Up/Down` | ±5% screen brightness     |
| `Play / Pause`       | Media play / pause        |
| `Next / Prev`        | Next / previous track     |
